# myapp

A project created with FastAPI CLI.

## Quick Start

### Start the development server

```bash
uv run fastapi dev
```

Visit http://localhost:8000/docs

Health: `GET /api/v1/health`

## Project Structure

- `app/main.py` - FastAPI 工厂与入口
- `pyproject.toml` - 依赖与 `[tool.fastapi] entrypoint`
